# Animated Flower

A small HTML, CSS, and JavaScript flower animation. Bootstrap's responsive
container keeps the message sized for phones and larger screens; the flowers
remain animated with the original CSS.

## Run it

Open `index.html` in a browser and select **CLICK AQUÍ**, or open `flower.html`
directly to view the animated flowers.

## Project structure

- `index.html` — greeting and link to the animation.
- `flower.html` — animated flower scene and message.
- `css/style.css` — greeting page styles.
- `css/main.css` — flower scene and animation styles.
- `img/flowers.png` — page icon.
- `anim.js` — reveals the message.
- `main.js` — starts the CSS animations after the page loads.
